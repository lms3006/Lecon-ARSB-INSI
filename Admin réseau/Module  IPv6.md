### ❓ Comment en est-on arrivé à IPv6 ?

#### 🕰️ Avant IPv6 : les anciennes versions

### 🔹 IPv5 ? (Une confusion fréquente)

👉 Il n’existe **pas vraiment d’IPv5 utilisé pour Internet** comme IPv4 ou IPv6.

Cependant :

- Dans les années 1970–1980, un protocole appelé  
    **Internet Stream Protocol (ST)** a été développé
- Ce protocole utilisait le **numéro de version 5**, d’où le nom **IPv5**

👉 Mais :

- Il était destiné au **streaming (voix, vidéo)**
- Il n’a **jamais été adopté à grande échelle**
- Il a été **abandonné**

✅ Conclusion :  
👉 **IPv5 n’est pas une vraie version d’Internet utilisée aujourd’hui**

---

### 🔹 IPv4 (la version actuelle la plus utilisée)

- Créé dans les années 1980
- Utilise des adresses de type :
    

- 192.168.1.1
    
- Taille : **32 bits**

👉 Problème majeur :

- Nombre limité d’adresses (~4,3 milliards)
- Aujourd’hui → **presque épuisé**

---

### 🚀 Pourquoi IPv6 ?

Pour résoudre les limites d’IPv4 :

1. 🔢 **Beaucoup plus d’adresses**
    - IPv6 = **128 bits**
    - Nombre énorme d’adresses (quasi illimité)
2. 🔒 **Sécurité améliorée**
    - Support natif de **IPsec**
3. ⚡ **Meilleures performances**
    - Routage plus efficace
4. 🌍 **Fin du NAT (Network Address Translation)**
    - Chaque appareil peut avoir une adresse publique

---

### 🔹 IPv6 (la nouvelle génération)

#### 📌 Format d’adresse

Exemple :

2001:0db8:85a3:0000:0000:8a2e:0370:7334

👉 Simplifié :

2001:db8:85a3::8a2e:370:7334

---

### 🔍 Différences IPv4 vs IPv6

|Caractéristique|IPv4|IPv6|
|---|---|---|
|Taille|32 bits|128 bits|
|Format|Décimal|Hexadécimal|
|Exemple|192.168.1.1|2001:db8::1|
|Nombre d’adresses|Limité|Très grand|
|NAT|Nécessaire|Pas nécessaire|

---

### 💡 Résumé simple

- **IPv5** → expérimental (Internet Stream Protocol), abandonné ❌
- **IPv4** → utilisé aujourd’hui mais limité ⚠️
- **IPv6** → solution moderne, futur d’Internet ✅
