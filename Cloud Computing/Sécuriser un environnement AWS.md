
**Pourquoi sécurisé AWS ?**

AWS offre une infrastructure puissant, mais la sécurité dépend fortement de :

- la configuration correcte
- la contrôle des accès
- la surveillance
- la traçabilité des action.

N.B : Un audit permet de vérifier que l'environnement respecte les bonnes pratiques

**Audit Cloud**

Définition

Un audit de sécurité cloud est une visant à :
- analyser les configuration
- identifier les failles
- vérifier la conformité
- renforcer la gouvernance.

**Principes fondenmentaux**

I- Cloude Trial logs et audit trial

CloudTrial enregistre :

Objectif de l'audit
